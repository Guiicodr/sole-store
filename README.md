# 👟 Sole Store — Premium Sneakers E-Commerce

E-commerce platform for premium sneakers built with **React** + **Vite** (frontend) and **Express** (backend).

## 🛠️ Tech Stack

### Frontend
- **React 19** + **Vite**
- **Tailwind CSS 4** — utility-first styling
- **React Router 7** — SPA navigation
- **Framer Motion** — animations
- **Lucide React** — icons
- **Swiper** — carousels

### Backend
- **Express** — Node.js REST API
- **PostgreSQL** (Railway)

## 📱 Responsividade

Totalmente responsivo utilizando **Tailwind CSS**:

- **Navbar**: menu mobile com toggle hamburger (`md:hidden`)
- **Grids**: layout adaptável (`md:grid-cols-4`, `lg:grid-cols-2`)
- **Hero**: grid de 2 colunas no desktop, empilhado no mobile
- **Sessões**: padding responsivo com `section-padding`
- **Footer**: 4 colunas no desktop, empilhado no mobile
- **Imagens**: aspect ratio consistente em todos os tamanhos de tela

## 🚀 Getting Started

### Frontend

```bash
cd client
npm install
npm run dev
```

### Backend

```bash
cd server
npm install
npm run dev
```
